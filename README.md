# Student Management System

A responsive web-based Student Management System developed using HTML, CSS, and JavaScript.

## Features
- Add Student
- Edit Student
- Delete Student
- Search Student
- LocalStorage Support
- Responsive UI

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Purpose
This project was developed to understand CRUD operations, DOM manipulation, and browser storage using LocalStorage.

## How to Run
1. Download project files
2. Open index.html in browser
